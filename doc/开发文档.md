# 横版枪战开发文档

初版是双人同屏对战。打开主菜单后点「开始」，会随机生成一张多层平台图，两名玩家拿着手枪 A 开战。对局中按 Q 暂停。场景、人物、子弹、菜单都由代码生成，不绑预制体也能玩。

## 1. 你需要在 Cocos 编辑器里做的事

工程是 Cocos Creator **3.8.6**。脚本已经放在 `assets/scripts` 里。编辑器里只需要一个空节点把入口脚本挂上。按钮、血条、平台都不用手摆。

1. 用 Cocos Creator 3.8.6 打开本工程，等右下角脚本编译结束。
2. 在资源管理器的 `assets` 上右键，新建场景，命名为 `Main`，双击打开。
3. 在层级管理器空白处右键，创建空节点，命名为 `GameRoot`。
4. 选中 `GameRoot`，在属性检查器里「添加组件」，搜索 `GameApp` 并加上。
5. 保存场景。编辑器预览会运行**当前打开的场景**，所以预览前确认打开的是 `Main`。
6. 点预览。先用鼠标点一下游戏画面，键盘才会进到游戏里。玩家 2 用小键盘时，先打开 **NumLock**。

新建场景自带的 Main Camera 可以留着。运行时 `GameApp` 会关掉它，避免 3D 天空盒盖住 2D 画面。

预制体现在可以不建。属性检查器里 `GameApp` 上那几项预制体都是空的，游戏会用色块代替。

## 2. 操作

| 动作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左右移动 | A / D | 左 / 右 |
| 跳跃（可二连跳） | W | 上 |
| 下穿脚下的平台 | S | 下 |
| 普通攻击 | J | 小键盘 1 |
| 特殊攻击 | K | 小键盘 2 |
| 暂停菜单 | Q | Q |

暂停菜单里有「继续」「重新开始」「回到主界面」。Q 只负责打开菜单，关闭要按按钮。

主菜单上方约 80% 是选人。左边 P1，右边 P2。每边从上到下是名称、横向的初始武器（贴图和名字，点一下选中）、按键提示。下方约 20% 是「开始游戏」。选「随机」时，每条命开始都会换一把初始武器，死亡后再随机一次。

一方生命耗尽后弹出胜负，可以重开或回主菜单。重开会再随机一张地图。

## 3. 规则怎么落地

长度单位是**人物宽度**。代码里 1 个宽度 = `GameConfig.charWidth`（40 像素）。人物宽 40、高 64。

- 移动速度：每秒 8 个宽度。
- 生命：每人 100 血、5 条命。血条和命数都画在画面最下方，左玩家 1，右玩家 2。血归零扣 1 条命并在出生点复活，带短暂无敌。命扣完则失败。
- 二连跳：站在地上时有 2 次跳跃。从平台边缘走下去时，这两次都还在，所以空中仍能跳两次。
- 下穿：只有站在**高度大于 0** 的平台上按向下才会落下。高度 0 是整张图最底下的地面，不能穿。这里的「高度」是相对地面的高度，不是平台厚度。
- 跳跃或下穿落地时，脚下中心会扬起一圈灰尘，向外扩散约 1 个角色宽。从平台边缘走下去再落地不会扬尘。
- 一方死亡（血量归零）后丢掉手上的特殊武器，换回 Desert。插在身上的刀和箭也会清掉。隐身会一起取消。
- 地图宽是画面的 2 倍、高是画面的 3 倍。每张图有 7 到 8 层，层间距大约 2.4 个角色宽，能从下一层跳上去。镜头把所有存活玩家和场上的武器箱框在一起，身体或箱子离屏幕边缘至少 4 个角色宽。需要缩小时会平滑拉远，大约三分之一秒跟上，不会在箱子刷新时猛地一缩。放大仍然立刻发生，并且不会超过开局把两名玩家框进画面时的大小，开局画面就是最大放大。血条和菜单不跟着缩放。
- 武器箱：开局 15 秒后，之后每 15 秒在随机平台上刷一个。旧的还在就会被新的换掉。碰到的人随机得到 FAMAS、M4_MK、MAC-10、Sawed_Off、Bow、AK47、AWM、Javelin 或 Knife；如果已经是同一把，则把弹药补满。
- Desert 的普通射击和扔弹匣各算各的子弹。普通攻击近距离伤害 10。普通弹和弹匣速度每秒 16 个角色宽。弹匣伤害 5，命中眩晕 1 秒。约在前方 4 个角色宽处升到最高，比出手点高约 1 个人物高度，然后下落。扔出弹匣后开始换弹，换弹结束时普通攻击弹药回满；从扔出到换弹结束不能普通攻击。底部只显示普通弹药，不显示弹匣数量。
- 初始武器弹匣打空后换弹，备弹无限，不会因此丢掉这把枪。Desert 普通攻击和扔弹匣分开计算。Desert_Gold、Desert_Double、Revolver、G18 两种攻击共用一个弹匣。
- 初始武器还有 Desert_Gold（弹容 9，普通伤害 15；特殊攻击撒 10 张绿钞，扣 10 血，本次生命所有武器伤害 +5%，可叠可致死，不在界面显示。有层数时，用任意武器击杀会回复层数 ×5 的生命，不超过 100）、Desert_Double（两种攻击都是 Desert 普通射击，弹容 14）、Revolver（弹容 6；普通攻击按下后松开就射出，不再需要蓄满，没有瞄准线，按住时能移动，射速是 Desert 的一半，弹速和弹长各 2 倍，伤害 35，不衰减；特殊攻击不蓄力，射速是 Desert 的 1.5 倍，散布是 MAC-10 特殊的 1.5 倍，1.8 个角色宽内伤害 25，到 3.5 个角色宽降到 15，再远为 0）、Broadsword（贴图是武士刀。轻击先向前冲 1 个角色宽，再横斩或突刺，两者交替，后摇 0.1 秒和 0.15 秒，后摇结束 0.5 秒内再按才会换招，伤害 20；重击先向上跳，高度是普通跳跃的 0.8 倍，这次起跳不消耗二段跳，刀从下向上扬，垂直判定比身高再大 50%，后摇 0.5 秒，伤害 40，落地后才能再放重击）、G18（弹容 17，普通和特殊的近距离伤害都是 6。普通射速是 Desert 的 1.8 倍；特殊攻击是连发，射速是 MAC-10 特殊的 0.8 倍）。死亡后回到自己选的初始武器。打空的特殊武器也换回这一把，不会中途改随机结果。
- FAMAS、M4_MK、MAC-10、Bow、AK47、Javelin、Knife 打空后消失，换回满弹 Desert。Sawed_Off 枪内 2 发、备弹 4 发。AWM 枪内 1 发、备弹 4 发，拉栓 0.5 秒，备弹打完才换回 Desert。
- 单发要松开再按。连发按住就射。FAMAS 普通射速是原来的 80%（每分钟 480 发），弹匣 25。特殊攻击是三连发，子弹比普通攻击快 10%，散布为 1 度；弹药不足 3 发时会把剩下的一次打完。FAMAS 普通攻击近距离伤害 22.5，比原来少 10%，三连发仍是 25。FAMAS 的射程比 M4_MK 远 20%。M4_MK 普通弹近距离伤害 20，比原来少 20%，散布是 4 度。M4_MK 特殊攻击每分钟 100 发，近距离每颗弹丸 4.9、稍远 2.8，消耗 5 发，不够 5 发也能打，打完弹匣清空并丢掉这把枪。每把枪的 `falloff` 各自独立。
- AK47 以 M4_MK 为底，射速高 15%，射程近 10%，散布 6 度，近距离伤害 28。特殊攻击是枪托，打中面前 1 个角色宽内的敌人，5 点伤害、0.5 击退、0.5 秒眩晕，挥击期间不能开枪，不耗弹。挥击时人会前倾，枪绕枪口把枪托抡到身前。
- 眩晕期间目标头上有两圈线条，并绕着转星星和月牙。打死并复活的那一下不会把眩晕带到新的一条命上。
- AWM 弹匣 1、备弹 4，拉栓 0.5 秒，伤害 80，子弹长度 18，速度每秒 44 个角色宽，飞出画面才消失。按住普通攻击蓄力最多 1 秒，蓄力越久散布越小，松开才射击；刚按下时散布 24 度，拉满为 0。蓄力时不能左右移动，但可以按左右转向，也可以跳和下穿，并画出瞄准线。特殊攻击切换隐身，灰尘和瞄准线仍然可见。死亡后隐身取消。
- Javelin 普通攻击先朝目标直线飞去，速度全程不变。每秒最多转 45 度。进入 3 个角色宽后改为红外制导，导引头视场约 40 度；在这之前，目标绕到弹头后方就丢失。丢失后保持当时的方向，不再追。直线逃跑时导弹更快，转角也够用，躲不开。跳起或下穿绕到导弹后面可以甩掉。跟踪最长 10 秒，之后熄灭下坠。命中或下坠撞到人会按弹体周围 2 个角色宽爆炸，伤害 40。特殊攻击一次射出上 15 度、水平、下 15 度三枚不失效的导弹，速度减半，弹头为红色。
- Knife 普通攻击每分钟 240 发，平抛小刀并持续旋转，下坠和弓箭蓄满之前一样（每秒² 1 个角色宽）。命中后留在身上，目标死亡时消失。特殊攻击每分钟 180 次，向前刺出，打面前 0.8 个角色宽，20 点伤害和 0.5 击退，刺击期间不能扔刀，不耗弹。弹匣 9。
- MAC-10 两档射击的伤害都是原来的一半，近距离 10。Sawed_Off 普通攻击每分钟 250 发，特殊攻击每分钟 500 发，两种攻击共用刚刚那一发的间隔，打完普通攻击不能马上特殊攻击。特殊攻击 15 颗弹丸，近距离每颗 8、合计 120，飞过 1.8 个角色宽后每颗 7、合计 105，全部打中都超过 100 血。
- Bow 按住普通攻击或特殊攻击都会拉弓，松开才射出。射出后要等下一支箭：普通攻击 0.4 秒（每分钟 150 发），三连箭 2 秒（每分钟 30 次）。箭速每秒 34 个角色宽。蓄力 0 到 0.5 秒。刚按下就松开时下坠较大（每秒² 12 个角色宽），拉满时下坠是每秒² 0.75 个角色宽。命中后箭留在身上，直到目标死亡。特殊攻击同时射出上 30 度、水平、下 30 度三支箭，也要蓄力，消耗 3 发。弹容量 9，打空后这把弓消失。
- 子弹长度以原来那颗 16 像素的子弹为 1。Desert 和 MAC-10 是 2，FAMAS 与 M4_MK 的普通弹是 4，Bow 是 5，Sawed_Off 和 M4_MK 的霰弹是 6，AWM 是 18。弹尾在枪口，弹头朝前。特殊武器弹速（人物宽度/秒）：FAMAS 普通 14、三连发 15.4，M4_MK 普通 14，MAC-10 13，Bow 34，AWM 44。Desert 普通弹和弹匣都是 16。
- 散布写的是角度。弹道在 `-spread` 到 `+spread` 度之间随机。数字越大越散。当前：FAMAS 1，M4_MK 普通 4，AK47 6，MAC-10 普通 8、特殊 16，Sawed_Off 20，M4_MK 霰弹 34。AWM 蓄力从 24 收到 0。
- 击退按武器上的「人物宽度」做一段 0.12 秒的滑动，滑过的距离大约就是这个数。
- 子弹、弹匣、霰弹和箭都会穿过地板。飞出画面左右 5 个角色宽，或飞出画面底部 10 个角色宽后消失。`falloff` 里某一档伤害为 0 时，飞到那个距离就提前消失。霰弹最后一档是 0，其他武器没有这一档。
- 两名玩家身体互不阻挡，子弹打不中自己。

武器数值在 `assets/scripts/config/GameConfig.ts` 的 `Weapons` 里，和需求一一对应。

## 4. 代码结构

| 文件 | 职责 |
| --- | --- |
| `assets/scripts/core/GameApp.ts` | 唯一要挂到节点上的组件。创建画面、菜单、对局循环、子弹、武器箱、胜负 |
| `assets/scripts/config/GameConfig.ts` | 分辨率、速度、散布、三把武器的数值 |
| `assets/scripts/core/InputHub.ts` | 键盘状态。区分「按住」和「刚按下」，避免单发武器被系统连发带成全自动 |
| `assets/scripts/actor/Fighter.ts` | 移动、跳、下穿、受击、姿态 |
| `assets/scripts/combat/Weapons.ts` | 射速、弹匣、装填、三连发、打空换枪 |
| `assets/scripts/world/ArenaBuilder.ts` | 四张多层地图，开局随机一张 |
| `assets/scripts/ui/GameWidgets.ts` | 按钮、血条、底部信息 |
| `assets/scripts/core/NodeFactory.ts` | 创建节点、文字、色块、实例化预制体 |

对局中每一帧的顺序：

1. 读键盘。对局中若刚按下 Q，进入暂停，这一帧不再模拟。
2. 移动两名玩家（重力、落地、下穿、击退）。
3. 检查是否碰到武器箱。
4. 按武器规则生成子弹。打空的特殊武器立刻换回手枪。
5. 移动子弹。弹道穿过地板，打到人，或飞出左右 5 个角色宽、底部 10 个角色宽后消失。伤害按已经飞过的距离从 `falloff` 里取，取到 0 就销毁。
6. 刷新武器箱计时。
7. 把姿态和血条画出来。有人没命了就弹出胜负。

暂停和胜负时停在第 1 步，人物会停在画面上。

## 5. 改数值

都在 `GameConfig.ts`。

- 人物宽度像素：`charWidth`。改它会同时改变移动、子弹、击退和平台间距的手感，因为地图也是按「几个角色宽」摆的。
- 手感：`motion` 里的 `moveSpeed`、`gravity`、`jumpSpeed`。现在一跳大约能上 3 个角色宽度，用来够到第一层平台。
- 武器：改 `Weapons` 里对应字段。`speed`、`knockback`、`gravity` 用角色宽度；`falloff` 是 `[[飞过的角色宽, 伤害], ...]`，按距离升序，伤害 0 表示飞到那里销毁。`rpm` 是每分钟次数；`trigger` 为 `semi`（单发）、`auto`（按住连发）、`burst`（点射）、`charge`（按住蓄力、松开发射）。`pelletCount` 是一次打出的弹丸数，`ammoCost` 是这次消耗的弹药。
- 散布：`spread.rifle`、`spread.smg`、`spread.smgHeavy`、`spread.shotgun`、`spread.shotgunWide`，单位是度。
- 弹道出界：`bulletBounds.side`、`bulletBounds.below`，单位是角色宽度。
- 武器箱间隔：`crateInterval`，单位秒。
- 复活无敌：`respawnInvuln`。

改完保存，等编辑器编译，再预览。不用改场景。

## 6. 加一张地图

编辑 `assets/scripts/world/ArenaBuilder.ts` 的 `Layouts`，追加一项：

```ts
{
    name: '新地图名',
    bg: new Color(30, 30, 40, 255),
    plats: [
        { x: -8, elevation: 2.5, w: 10 },
        { x: 0, elevation: 4.8, w: 8 },
    ],
}
```

- `x`、`w`、`elevation` 的单位都是人物宽度，`x` 相对画面中心。
- `elevation` 是台面高出地面多少。不要写 0，0 只留给最底下那条不能下穿的地面，地面是代码自动加的。
- 第一层 `elevation` 不要超过约 2.6，否则从地面跳不上去。
- 更高的平台要在水平方向上盖住下面那层，否则隔空跳不过去。跳跃高度大约 3 个角色宽，水平速度只有每秒 2 个角色宽。

出生点固定在地面左右两侧，在 `buildArena` 的 `spawns` 里。

## 7. 加一把武器

在 `GameConfig.ts` 的 `Weapons` 数组加一项，`id` 不要和现有的重复。然后到 `assets/scripts/combat/Weapons.ts` 的 `randomSpecialWeapon` 里，把新 id 放进随机列表。如果不想进武器箱，就不要放进那个函数，以后可以用别的方式 `createWeapon('新id')`。

`onEmpty: 'revert'` 表示打光消失并换回本局选的初始武器。`onEmpty: 'reload'` 表示按该攻击模式自己的 `reloadTime` 装填。`sharedMagazine: true` 时两种攻击扣同一个弹匣，容量看 `primary.magazine`。

枪械贴图在 `assets/resources/weapons/`，文件名和武器 `id` 相同：

| 文件 | 武器 |
| --- | --- |
| `pistol.png` | Desert |
| `desert_gold.png` | Desert_Gold |
| `desert_double.png` | Desert_Double |
| `revolver.png` | Revolver |
| `broadsword.png` | Broadsword |
| `g18.png` | G18 |
| `random.png` | 随机 |
| `rifle.png` | FAMAS |
| `rifleb.png` | M4_MK。没有单独画时可以先复制 FAMAS |
| `smg.png` | MAC-10 |
| `shotgun.png` | Sawed_Off |
| `bow.png` | Bow |
| `ak47.png` | AK47 |
| `awm.png` | AWM |
| `javelin.png` | Javelin |
| `knife.png` | Knife |

图要朝右画，最左边是握把或枪托。换图后回到编辑器，等资源导入完成再预览。加载成功后，人物手上的色块会换成对应贴图，面朝左时自动翻转。新武器只要放一张同名 png，并在 `GunSprites.ts` 的加载列表里加上这个 id。

## 8. 预制体（可以后做）

选中 `GameRoot` 上的 `GameApp`，把预制体拖进对应槽位。不拖就继续用色块。

| 槽位 | 约定 |
| --- | --- |
| platformPrefab | 平台。生成时锚点会被改成顶部居中 `(0.5, 1)`，并按这块平台的宽高缩放。请让图的主体填满根节点的 UITransform |
| playerPrefab | 人物。脚底对准根节点，默认朝右。脚本会把锚点设成 `(0.5, 0)`。根节点上如果有动画，并且片段名叫 `Idle`、`Run`、`Jump`、`Drop`，会按姿态播放；没有动画时，朝向用缩放，跳跃会歪一下，下穿会压扁 |
| cratePrefab | 武器箱 |
| bulletPrefab | 普通子弹，默认朝右，飞行时会按速度方向旋转 |
| magPrefab | 手枪扔出的弹匣，同样默认朝右 |

当前战斗画在 Canvas 上，用的是 UI 相机。请用 **Sprite 这类 2D 预制体**。立体模型挂上来不会出现在这台 UI 相机里。若要改成 Cocos 自带的 3D 胶囊体，需要另开一台正交场景相机，那是下一步，不是现在这版。

## 9. 这版没有做的
